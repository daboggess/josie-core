# Model Routing

Josie is provider-neutral. Current local inference is one replaceable engine.

Use patterns intentionally:

- **Local first:** private, repeated, offline, low-cost, bounded planning.
- **Independent witnesses:** origin testimony and high-stakes disagreements.
- **Adversarial review:** ask a reviewer to find errors rather than agree.
- **Specialist routing:** match task to demonstrated capability.
- **Live verification:** use current primary sources for unstable facts.
- **Reconciliation:** preserve who said what and why conclusions differ.

Model consensus is not truth. Cloud use requires the applicable approval and
budget. Current Sophie/Bernie routing is manual, zero-spend, draft-only. Model
outputs cannot execute actions or modify governance.
